# CardTalk

SPA для изучения иностранных слов. Карточки со словами, перевод, категории, профиль с расширенной формой, авторизация через http-only cookies.

## Стек

- React 18
- TypeScript
- Redux Toolkit + RTK Query
- React Router v6
- React Hook Form + Zod
- MSW (Mock Service Worker) для моков API
- Vite
- CSS Modules

## Что было реализовано

- Авторизация через `POST /api/authorization` с установкой http-only cookies
- Автоматическое обновление токена при 401 через `baseQueryWithReauth`
- Защищённые маршруты `/cards` и `/profile`
- Карточки со словами: переворот по клику, случайный заголовок с мотивирующей (или ироничной) фразой, фильтр по темам
- Профиль из 20 полей всех типов: строка, число, текст, дата, select, checkbox, radio
- Связь полей: при выборе определённого значения одни поля скрываются, другие блокируются с предустановленным значением (поле о семейном положении)
- Кастомный Select через порталы с позиционированием и флипом вверх
- Toast-уведомления
- Все API-запросы замоканы через MSW
